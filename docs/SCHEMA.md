# Database Schema Documentation

## Tables

### cases
Stores support cases from CRM systems.

```sql
- id (integer, PK)
- case_id (string, unique) - External case ID from Salesforce, ServiceNow, etc.
- system (string) - Salesforce, ServiceNow, Zendesk
- customer (string)
- title (string)
- description (text)
- status (string) - open, in_progress, resolved
- error_code (string) - For easier searching
- application (string)
- ai_summary (text) - Generated by LLM
- troubleshooting_steps (text) - Generated by LLM
- created_at (datetime)
- updated_at (datetime)
- closed_at (datetime)
```

### events
Tracks all activity events.

```sql
- id (integer, PK)
- event_type (string) - CRM_CASE_OPENED, CALL_STARTED, etc.
- case_id (string, FK)
- source (string) - screenpipe, browser_extension, teams_integration
- data (json) - Event-specific data
- screenshot_path (string) - Path to captured screenshot
- ocr_text (text) - Extracted text from screenshot
- created_at (datetime)
- processed (datetime) - When this event was processed
```

### context_state
Current operational context (singleton).

```sql
- id (integer, PK)
- crm_case (string)
- crm_system (string)
- customer (string)
- call_active (boolean)
- remote_session_active (boolean)
- remote_host (string)
- active_application (string)
- active_url (string)
- window_title (string)
- last_suggestion (string)
- last_suggestion_time (datetime)
- updated_at (datetime)
```

### documents
Knowledge base documents.

```sql
- id (integer, PK)
- source (string) - RightAnswers, SharePoint, Documentation
- title (string)
- content (text)
- url (string)
- vector_id (string, unique) - Qdrant document ID
- tags (string) - comma-separated
- indexed (boolean)
- created_at (datetime)
- updated_at (datetime)
```

### memories
Personal memories and learned patterns.

```sql
- id (integer, PK)
- memory_type (string) - case_resolution, customer_preference, troubleshooting_pattern
- case_id (string)
- customer (string)
- title (string)
- content (text)
- vector_id (string, unique) - Qdrant ID
- relevance_score (string)
- created_at (datetime)
- accessed_at (datetime)
```

## Vector Database (Qdrant)

Collections for semantic search:

### cerebrus_documents
- Stores embeddings of knowledge base documents
- 1536-dimensional vectors (OpenAI embeddings)
- Payload includes title, source, and content preview
